# 济南·趵突泉公园核心园区 三维场地模型

基于公开导游图、航拍影像与文献资料，按真实尺寸等比例程序化复原的**趵突泉公园核心园区（约 10.5 公顷）交互式三维场地模型**。包含趵突泉泉池与三股水涌泉、观澜亭、泺源堂古建筑群、南门（泺源门）、万竹园、李清照纪念堂、枫溪–晴雨溪水系及园林植被，可在浏览器中自由旋转、缩放并点击景点查看介绍，也可一键导出 glTF/GLB 文件供 Blender / SketchUp 等建模软件导入。

> 打开 `index.html` 后即可看到完整三维园区；右上角面板可切换图层、俯视总览与导出模型。

## 在线运行 / 本地打开

仓库提供**两种版本**：

### 方式一：CDN 在线版（仓库根目录 `index.html`）

直接用现代浏览器（Chrome / Edge / Firefox / Safari）打开根目录 `index.html` 即可，首次打开需联网从 unpkg CDN 加载 Three.js r147，应用代码在本地、无其他依赖。也可将仓库直接部署到 GitHub Pages 等静态托管。

### 方式二：完全离线单文件版（推荐，无需联网）

运行构建脚本，它会自动下载 Three.js 依赖并把所有代码、纹理内联进**一个** HTML 文件：

```bash
cd baotuquan-model
python3 build/build.py
# 生成 dist/index.html（约 800 KB，双击即开，零网络请求、零依赖）
```

> 注：Python 仅用于构建；运行模型本身不需要 Python。

### 本地静态服务器（可选）

```bash
cd baotuquan-model
python3 -m http.server 8765
# 浏览器访问 http://localhost:8765/index.html
```

## 模型内容

- **趵突泉泉池**：东西 30 m × 南北 18 m、深 2.2 m 的石砌泉池，池西为观澜亭，池北临泺源堂，东架来鹤桥，南、东以长廊围合；三股泉眼偏池西，带涌泉粒子与扩散涟漪动画（日涌约 7 万 m³、水温常年 18℃）。
- **古建筑群（程序化古建构件复原）**：
  - 南门「泺源门」：东西 47.5 m、深 13 m、主门高 8.4 m，绿琉璃瓦歇山顶「勾连搭」组合，朱红金钉大门、红底金字乾隆御笔「趵突泉」匾、石狮、对称连廊与票房；
  - 观澜亭（明天顺五年建，黄琉璃瓦四角攒尖顶、水中石台基、四面白石栏）及亭南胡缵宗书「趵突泉」碑、池东「第一泉」碑、双御碑；
  - 泺源堂、娥姜祠、三圣殿「三大殿」南北轴线（黄琉璃瓦歇山飞檐、前月台临水）；
  - 万竹园（18 亩多进灰瓦四合院群，含望水泉、白云泉、李苦禅纪念馆）；
  - 李清照纪念堂三院式仿宋建筑群（漱玉堂、静治堂、易安旧居）及漱玉泉、马跑泉、柳絮泉、金线泉、龟石；
  - 白雪楼·大戏台、沧园（王雪涛纪念馆）、尚志堂、望鹤亭茶社、蓬山旧迹坊、枫榭、枫溪桥等；
- **水系**：枫溪横贯中部、晴雨溪通东门、白龙湾及护城河环绕，漱玉泉、杜康泉、登州泉等二十余处名泉以石栏小池表达；
- **地形与植被**：平坦园址 + 1964–65 年挖湖堆山形成的北部小丘；阔叶树、垂柳、松树、竹丛、灌木按水面与建筑避让规则实例化布置；
- **周边环境**：南界泺源大街、东界趵突泉南路与泉城广场（含泉标示意）、东/北护城河及远景城市体量。

## 坐标与尺度约定

- 世界坐标 1 单位 = 1 米；X 轴向东、Z 轴向北、Y 轴为高程；南门中点约为原点 `(0, 0)`，泉池中心约 `(-40, 180)`。
- 公园边界依官方导游图轮廓描点（南北约 470 m，南宽北窄），核心建筑尺寸采用文献/官方公布数据，其余景点按导游图相对位置等比例布置。

## 精度声明（务必阅读）

本模型是**基于公开资料的等比例示意性复原，不是测绘级成果**：

- 建筑的面阔、进深、屋顶形制与朝向依据公开文字资料与航拍/导览影像推断，未使用测绘图纸，细部斗拱、彩画、装修做了概括化表达；
- 景点平面位置由导游图与航拍图人工配准，存在米级误差；名泉池形状多为示意；
- 树木、山石、铺地、纹理均为程序化生成的风格化表达，不代表真实单体；
- 如需用于工程、规划、出版等正式用途，请以济南市园林和林业绿化局 / 景区官方测绘资料为准。

## 导出 glTF/GLB 说明

- 点击页面右上角导出按钮，经 GLTFExporter 生成 GLB（glTF 2.0 二进制），可直接拖入 Blender（建议 3.2+）、SketchUp（需 glTF 导入插件）、Windows 3D 查看器等；
- 导出坐标系与页面一致（米制，Y 向上）；
- 导出时会临时隐藏天空球、涌泉粒子与园林植被（植被为 InstancedMesh 实例化对象，r147 GLTFExporter 对其支持有限），并将动态 Shader 水面临时替换为半透明标准材质，以保证在其他软件中正常显示；
- 已对导出文件做结构校验（glTF 2.0、JSON/BIN chunk 完整）。

## 技术说明

- 纯前端、零外部图片依赖：全部砖瓦、琉璃、铺装、门钉等纹理由 Canvas 程序化绘制；
- 水面为自定义 GLSL Shader（多频波纹、菲涅尔、动态高光），涌泉为粒子 + 扩散环动画；
- 植被使用 `InstancedMesh` 单次绘制，整园约 5000+ 网格、约 16 万三角面，普通笔记本核显亦可流畅运行。
